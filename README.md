## How I work
- **Evidence over assertion.** A control that exists is not proof that it operates. Ratings reflect the evidence actually obtained.
- **Primary sources.** Citations are checked against the source text: POPIA sections, NIST publications, ISO Annex A.
- **Plain language.** Findings are written so a business owner can act on them.
